Creator Campaign Hub

Comprehensive Campaign Tracking & Analytics Platform

Live URL: https://creator-campaign-hub.vercel.app

Project Overview

Creator Campaign Hub is a full-stack web application designed to help content creators and marketers track, manage, and analyze their marketing campaigns. The platform provides real-time tracking of views and clicks, comprehensive analytics dashboards, and an embeddable tracking system that can be integrated into any website or application.

This project demonstrates expertise in modern web development, including React frontend architecture, PostgreSQL database design, serverless functions, and real-time analytics. The system is built with scalability and security in mind, featuring role-based access control, automated metric calculations, and a robust API for external integrations.

Key Features

📊 Campaign Management

Create, edit, and manage multiple marketing campaigns with custom CPM (Cost Per Mille) and CPC (Cost Per Click) rates. Track campaigns through their lifecycle from draft to active to completed status.

👥 Creator Management

Organize campaigns by creators, allowing you to track performance across different content creators and manage relationships effectively.

📈 Real-Time Analytics

View comprehensive dashboards showing total views, clicks, CTR (Click-Through Rate), and estimated payouts. All metrics are calculated in real-time as events are tracked.

📉 Event Visualization

Interactive charts displaying view and click events over time, helping you identify trends and optimize campaign performance.

🔗 Embeddable Tracker

Lightweight JavaScript tracking script that can be embedded in any website. Automatically tracks views from URL parameters and clicks on links containing campaign IDs. Includes target link validation to restrict tracking to specific URLs.

🎯 Target Link Restrictions

Configure campaigns with target links to restrict tracking to specific URLs. The tracker automatically validates the current page URL against the target link before tracking events, ensuring accurate attribution.

✅ Script Verification

Built-in link checker that verifies if the tracker script is properly installed on external websites. Enter any URL to instantly check if the script tag is present and correctly configured.

🔌 Public API

RESTful API endpoints for tracking views and clicks programmatically. Supports multiple integration methods including cURL, JavaScript Fetch, and Python Requests. Includes campaign info endpoint for target link validation.

✏️ Manual Event Entry

Add view and click events manually through the dashboard interface, useful for testing or recording offline events.

🔐 Secure Authentication

User authentication and authorization system with role-based access control. Each user can only access their own campaigns and data.

💰 Automatic Payout Calculation

Automatically calculates estimated payouts based on views (CPM) and clicks (CPC) using the formula: (Views ÷ 1000 × CPM) + (Clicks × CPC)

📋 Shareable Campaign Links

Generate ready-to-share campaign links with campaignId parameters pre-configured. One-click copy functionality makes it easy to share tracking links with creators and partners.

Authentication Layer
  • Supabase Auth for user authentication
  • Automatic profile creation on signup

Database Layer (PostgreSQL)
  • Row Level Security (RLS) policies for data isolation
  • Database functions for metric calculations
  • Triggers for automatic timestamp updates
  • Public insert policy for tracking API
API Layer (Supabase Edge Functions)
  • track-view: Handles view event tracking
  • track-click: Handles click event tracking
  • get-campaign-info: Returns campaign target_link and status for validation
  • check-script: Verifies script installation on external URLs
  • CORS-enabled for cross-origin requests
  • Automatic metric updates after event insertion
Tracking System
  • Embeddable JavaScript tracker (tracker.js)
  • Auto-tracking from URL parameters
  • Target link validation before tracking
  • Campaign status verification
  • Automatic click tracking on links
  • Manual JavaScript API for programmatic tracking
  • Script verification tool for external sites

Data Flow

  1. Event Tracking: External website includes tracker.js script or calls API directly
  2. Target Link Validation: Tracker fetches campaign info and validates current URL against target_link (if set)
  3. Campaign Status Check: Verifies campaign is active before proceeding with tracking
  4. API Processing: Edge function receives event, validates campaign_id, and inserts into database
  5. Metric Calculation: Database function automatically recalculates views, clicks, CTR, and payout
  6. Real-time Updates: Frontend queries updated campaign data and displays in dashboard
  7. Visualization: Charts and tables update to reflect latest metrics

Tracking System

Embeddable Tracker Script

The tracker.js script is generated at build time with environment variables injected. It provides:

  • Automatic View Tracking: Detects campaignId in URL parameters and tracks views on page load
  • Automatic Click Tracking: Monitors all link clicks and tracks clicks for links containing campaignId
  • Target Link Validation: Automatically fetches campaign info and validates current URL against target_link before tracking
  • Campaign Status Check: Only tracks events for active campaigns, skipping draft or completed campaigns
  • JavaScript API: window.CampaignTracker.trackView() and window.CampaignTracker.trackClick() for manual tracking
  • Error Handling: Graceful error handling that doesn't interrupt user experience
// Usage Example <script src="https://creator-campaign-hub.vercel.app/tracker.js"></script> // Automatic tracking from URL: // https://example.com/page?campaignId=abc123 // Manual tracking: window.CampaignTracker.trackView('abc123'); window.CampaignTracker.trackClick('abc123');

REST API Endpoints

POST /functions/v1/track-view

Track a view event for a campaign

{ "campaign_id": "uuid-here" }

POST /functions/v1/track-click

Track a click event for a campaign

{ "campaign_id": "uuid-here" }

GET /functions/v1/get-campaign-info

Retrieve campaign information including target_link and status for validation

?campaign_id=uuid-here Response: { "campaign_id": "uuid", "target_link": "https://...", "status": "active" }

POST /functions/v1/check-script

Verify if tracker script is installed on a given URL

{ "url": "https://example.com" } Response: { "hasTrackerScript": true, "hasCampaignId": true, "scriptTags": [...] }

Security Features

🔒 Row Level Security

PostgreSQL RLS policies ensure users can only access their own data. Each table has carefully crafted policies that check user ownership.

🔑 Authentication

Supabase Auth handles secure user authentication with email/password. JWT tokens are used for API authentication.

🛡️ API Security

Edge functions validate campaign IDs and use service role keys for database operations. CORS headers are properly configured.

👤 Role-Based Access

Extensible role system (admin/user) allows for future permission management. Currently, all users have equal access to their own data.
